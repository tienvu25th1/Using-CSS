Nghệ Thuật Định Dạng Văn Bản Trực Quan Trong CSS

CSS cung cấp một hệ thống thuộc tính phong phú giúp nhà phát triển web kiểm soát tỉ mỉ cách văn bản hiển thị trên màn hình. Từ việc căn lề dòng chữ, tạo độ lùi đầu dòng cho chuẩn phong cách báo chí, cho đến việc lựa chọn kiểu phông chữ và màu sắc hài hòa.

"Kiến trúc trang web giống như trình bày một cuốn sách hay: Typography tốt sẽ dẫn dắt người đọc tiếp thu tri thức một cách tự nhiên và đầy cảm hứng."

Khi áp dụng thuộc tính lùi đầu dòng, văn bản sẽ có khoảng trống trang trọng ở mỗi đoạn mới. Bạn cũng có thể tìm hiểu thêm tài liệu chi tiết tại Trang học CSS W3Schools Việt Nam để củng cố kỹ năng làm chủ giao diện web.

Bảng Sửa Lỗi Từ Vựng & Thuộc Tính Định Dạng Văn Bản CSS

Cảnh báo từ vựng sai phổ biến trong bài tập CSS:

  • ❌ text-identation → ✅ Đúng phải là text-indent (Lùi đầu dòng).
  • ❌ text-style → ✅ Không tồn tại! Dùng font-style (thường/nghiêng) hoặc text-decoration (gạch chân).
Thuộc tính CSS Giá trị phổ biến Ý nghĩa / Chức năng
text-indent 20px, 2em, 5% Thụt/Lùi đầu dòng của dòng đầu tiên trong đoạn văn.
text-align left, center, right, justify Căn lề văn bản (Trái, Giữa, Phải, Đều 2 bên).
color #333, red, rgb(...) Thay đổi màu sắc chữ.
font-size 16px, 1.2rem, 100% Kích thước chữ.
font-style normal, italic Kiểu chữ đứng thẳng hoặc in nghiêng.
text-transform uppercase, lowercase, capitalize Chuyển đổi kiểu chữ in HOA, viết thường hoặc hoa đầu từ.
line-height 1.5, 1.8, 24px Chiều cao hàng/khoảng cách giữa các dòng văn bản.
